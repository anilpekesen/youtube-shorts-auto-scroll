# Privacy Policy — Auto Scroll for YouTube Shorts, Instagram Reels & TikTok

This extension does **not** collect, store, transmit or sell any personal data.

- No analytics, no tracking, no accounts.
- Your on/off settings are stored locally in your browser (`chrome.storage.local`).
- The extension periodically downloads a public configuration file (CSS selectors only) from
  GitHub (`raw.githubusercontent.com`) so it keeps working when a supported site changes its layout.
  No data about you is sent with this request.
- The extension only runs on `youtube.com`, `instagram.com` and `tiktok.com` pages.

Contact: open an issue on the project's GitHub repository.
